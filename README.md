Apple Picker

About the Game

Apple Picker is a 3D Unity game where the player controls baskets at the bottom of the screen to catch falling apples. The goal is to catch as many apples as possible while progressing through multiple rounds.

The game also includes branches that the player must avoid. Catching a branch causes the game to end.

Features

Start screen with a Start button

Four baskets instead of the original three

Four rounds of gameplay

Round display at the top of the screen

Score counter for catching apples

Falling branches that the player must avoid

Catching a branch causes Game Over

Game Over screen/message

Restart button to start a new game

Apples and branches are spawned automatically

Branches appear less frequently than apples

Player-controlled baskets follow the mouse

How to Play

Click the Start button to begin the game.

Move the mouse left and right to control the baskets.

Catch falling apples with the baskets to earn points.

Avoid catching branches.

Losing all of the baskets or catching a branch results in Game Over.

Click Restart to play again.

Scoring

Catching an apple: +100 points

Catching a branch: Game Over
